# ResumeAI — AI-Powered Resume Tailoring

**Live at: https://resume-tool-zeta.vercel.app**

Paste your resume + a job description. Get a tailored resume and personalized cover letter in 30 seconds, powered by Claude AI.

## Features
- ✅ ATS keyword optimization — gets past resume scanners
- ✅ Tailored bullet points for each specific role
- ✅ Custom cover letter for every application
- ✅ Multiple tones: confident, professional, creative
- ✅ Copy or download as text instantly
- ✅ First tailoring free

## Tech Stack
- Frontend: Vanilla HTML/CSS/JS
- Backend: Vercel Serverless Functions (Node.js)
- AI: Anthropic Claude API (claude-haiku-4-5)
- Payments: Cash App ($DzyNtwrk)

## Deploy Your Own

```bash
npm install
vercel --prod
vercel env add ANTHROPIC_API_KEY production
```
