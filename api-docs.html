POST /api/generate

Tailor a resume and generate a cover letter for a specific job description.

FieldTypeRequiredDescription
resumestringYesCandidate's current resume text
jobDescstringYesFull job description
namestringNoCandidate name for cover letter
rolestringNoRole title for cover letter
tonestringNoprofessional | confident | enthusiastic | concise
outputTypestringNoboth | resume | cover (default: both)
 
curl -X POST https://resume-tool.vercel.app/api/generate \
  -H "Content-Type: application/json" \
  -d '{
    "resume": "John Doe\nSoftware Engineer...",
    "jobDesc": "We are looking for a Senior Engineer...",
    "tone": "professional",
    "outputType": "both"
  }'
const res = await fetch('https://resume-tool.vercel.app/api/generate', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    resume: 'John Doe\nSoftware Engineer...',
    jobDesc: 'We are looking for a Senior Engineer...',
    tone: 'professional',
    outputType: 'both'
  })
});
const { resume, coverLetter } = await res.json();
import requests
r = requests.post('https://resume-tool.vercel.app/api/generate', json={
    'resume': 'John Doe\nSoftware Engineer...',
    'jobDesc': 'We are looking for a Senior Engineer...',
    'tone': 'professional',
    'outputType': 'both'
})
data = r.json()
print(data['resume'], data['coverLetter'])

FieldTypeRequiredDescription
